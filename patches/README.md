# Reviewed local dependency mitigation

`sprintf-js` 1.1.3 has no published fixed release for [GHSA-hp3w-g68c-fv3c](https://github.com/advisories/GHSA-hp3w-g68c-fv3c). The installed just-bash 3.4.2 uses it for `printf`; the latest observed just-bash 3.6.0 still declares `sprintf-js: ^1.1.3`. Removing `printf` or downgrading Eve would remove required functionality. This bounded local mitigation preserves the upstream package version, lockfile integrity, and BSD-3-Clause license.

The readable replacement is the original upstream `src/sprintf.js` with format, width, string precision, and cumulative output limited to 1,048,576 JavaScript code units and numeric precision limited to 100. Placeholder validation precedes argument callbacks and width/precision allocation. Normal smaller formatting remains compatible. These explicit limits reject previously accepted oversized output. The patch does not claim to bound arbitrary user-supplied callbacks, object serialization, or all possible formatting CPU costs.

`apply-dependency-patches.mjs` verifies the upstream and replacement SHA256 digests, exact installed/locked package identity, and canonical file containment before applying any change. It applies the same readable source to the Node and browser entry points. The unused upstream source map is no longer referenced by either entry. Repeated application is idempotent; unexpected bytes, versions, missing files, or unapplied checks fail closed. Review and retire this patch when upstream publishes a fix; do not simply adjust the expected hashes.

Normal `npm ci` runs the root postinstall. Every repository CI path using `--ignore-scripts` explicitly applies and verifies the mitigation. Other consumers installing with scripts disabled must run `npm run postinstall && npm run security:patches` before building or executing this source. The raw `npm audit` result remains unchanged by this source mitigation: five moderate package findings propagated from this one advisory. No package metadata, advisory, or gate is suppressed. A metadata-only zero-advisory gate remains blocked pending an upstream fixed release; installed-source mitigation must receive independent security review.
