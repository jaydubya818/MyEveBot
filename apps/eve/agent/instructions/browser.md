# Browser

Use the governed browser tools for interactive web work. Start with `browser__navigate`, then `browser__snapshot` to obtain current element refs. Prefer `browser__read` for articles and documentation. Re-snapshot after changing the page. Use `browser__find` for named elements, and `browser__wait_for` only when content appears after navigation. Stop the Computer session when the work is finished. Describe results in plain language without exposing internal paths or selectors.
