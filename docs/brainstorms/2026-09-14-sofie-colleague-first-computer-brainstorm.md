# Sofie Colleague-First Computer

## What We're Building

Complete Sofie's colleague-first loop: reliable production execution, durable delegated work with explicit outcomes and evidence, a Results Desk, promotion of successful work into repeatable routines, bounded chief-of-staff delegation, and supervised Computer execution through isolated browser, terminal, and file sessions.

## Why This Approach

Extend the existing Agent Runs, QA task ledger, Goal OS, routines, persistent Agents, and Agent Computer instead of introducing another workflow engine. One shared execution and artifact model keeps chat, UI, routines, specialists, and Computer work accountable and recoverable.

## Key Decisions

- One accountable parent Run: specialist and Computer work attach to it rather than creating competing completion claims.
- Evidence-backed completion: a Run cannot become completed until required checks and destination evidence pass.
- Ephemeral compute, durable state: Computer sessions are replaceable; approved artifacts and checkpoints persist.
- Isolated by default: each owner/Agent session has bounded tools, network policy, runtime, and audit state.
- Message-first, UI-governed: Sofie can create and operate every entity; UI supports review, approval, retry, pause, revoke, and deletion.
- Repetition follows success: Run again, Save as skill, and Make routine appear after a verified result.
- Production gating: deployment is not promoted without deterministic tests plus a real multi-turn chat and Computer smoke check.

## Open Questions

None blocking. Credentials, MFA, CAPTCHA, financial actions, external publication, and other irreversible side effects always pause for owner approval.
