# Knowledge in Total Recall

Typed Knowledge remains the canonical source for facts, observations, hypotheses, decisions, commitments, preferences and insights. Sources and provenance distinguish statements by the owner, files, connected services and agent inference. Work Knowledge retains the Work ownership boundary and supports explicit supersession while preserving history.

Total Recall does not copy private Work facts into unrelated Work or Relay. Current Knowledge and historical observations remain distinct from learning candidates and promoted advisory guidance. File sources retain identity, but this change does not qualify a new extraction/indexing service.
