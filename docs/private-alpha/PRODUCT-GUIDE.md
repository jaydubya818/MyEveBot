# Private-alpha product guide

Start at **Today** for active work, waiting items and recent results. **Ask Sofie** opens a conversation; **Work** keeps objectives and supporting evidence together. Use **Needs You** for explicit owner questions and **Approval Center** for scoped consequential proposals.

Before allowing a proposal, inspect the resource, effects, capability and expiration. Allowing records permission; it does not establish execution. To change a proposal, decline the original and draft a revision request. The draft does not send automatically. History is limited to the latest 100 records; Pending queries pending records directly.

**Inbox** shows channel setup and incoming email threads. Slack and Relay stay in their existing channel experiences until canonical Inbox integration supplies their normalized items. Channel messages do not grant authority. A transport outage appears as unavailable, not as an empty inbox.

**Search** finds Goals/Work, Results, Memory/Knowledge, artifacts, specialists and conversations with source labels. Goal/Result searches cover the latest 100 records and Knowledge the first 25 matching records. Unavailable sources are visible. **⌘K / Ctrl+K** opens navigation and conversation search; Escape closes it and returns focus. Tab stays inside the dialog.

**Team** lists persisted specialists, configured capabilities and limits. Use the existing specialist manager to create or edit one. A configured capability is not authority to take an action. Software Engineer stays unavailable until qualified canonical integration.

**Apps** shows actual connected accounts and provider status. Use the existing connection manager to inspect access or disconnect. Where per-operation scopes or last-used data are not supplied, the UI says so.

**Computer** exposes the existing session/profile workspace. Inspect activity and use takeover where supported. A UI view or takeover does not admit new Work or grant publication authority.

**Files** separates conversation uploads from generated artifacts. Open an artifact to preview its current revision, inspect revision history, edit, comment, download or explicitly share the selected revision. Review sharing expiry and revoke unneeded links. Conversation provenance is not independent verification.

**Daily Brief** and **Weekly Review** use existing review records. Weekly Review shows recorded progress, outcomes, blockers, missed commitments and proposed priorities. Delivery preferences remain in the existing manager. No learning or usage claim is invented when the review contract lacks that data.

**Privacy** explains the current topology: one configured owner per private instance. Sharing an instance password does not provide two-owner isolation. Use separate owner instances; shared business Goals/Results/Rooms await explicit canonical membership. Personal memory is not automatically shared. Capsules and governed learning promotion remain integration boundaries.

`/product-preview` is a clearly marked disconnected fixture. Its three approval examples and channel/candidate projections test presentation only; its decisions do not call live APIs.

## Known limitations

- Canonical Q37/Factory readiness, dispatch and live verification are not activated here.
- Final Capsules and governed-learning lifecycle integration are pending.
- Shared rooms and shared business resource access are not enabled.
- No production deployment or live two-owner/provider journey was run.

These are release limitations, not reasons to stop independent product work.
