## Decision and truth rules

Selecting a choice does not confirm it. Confirmation shows the exact sample revision, destination and effects. A successful local confirmation removes the action controls and moves keyboard focus to the receipt. Free-text continuation never approves a pending action. A later revision cannot inherit an earlier decision.

Failed verification suppresses the verified Result and publication choices. Expiration clears selection and requires fresh review. Retrying clears both the prior selection and confirmation. The sample reducer rejects unknown/cross-journey options, duplicate confirmation and confirmation before verification; this is UI behavior only, not an authority implementation.

Proof of Work expands inline: tests, candidate, evidence, producer, verification, artifacts and provenance. It explicitly distinguishes sample evidence from live receipts. Computer opens contextually inside the engineering conversation, with an honest no-session state; the existing workspace is available in a new tab. No screenshot or session is fabricated.
