## Implemented boundary

This is an internal personal-owner workflow for a small, bounded UTF-8 Node CLI repository. It includes persisted contracts, Runs and exclusive worker leases, retained candidate files/Git identities, generation fencing, protected black-box verification, explicit evidence states, exact publication approvals, guarded GitHub publication, current-state polling, bounded CI/review continuation, immutable Results and responsive Work UI.

The domain uses executor-neutral ports. Only Claude Code 2.1.282 is implemented; session resume and automatic failover are explicitly unsupported. The executor has no GitHub, database, provider or production credential. Its only model route uses an attempt-bound, budget-reserving broker. The verifier compares stdout and exit status outside candidate-controlled compute.

GitHub writes use dedicated Work branches and non-force updates. Durable engineering effect IDs record uncertain outcomes before publication and reconcile before any retry. **They are not canonical chat Action Gateway IDs.** Existing Action Gateway tests pass, but consolidating/reviewing this new publication boundary against the platform gateway is a remaining integration consideration, not an implied qualification.

Review continuation accepts an authorized reviewer's explicit structured attestation tying a protected check to an existing criterion and allowed path. Arbitrary freeform or expanded-scope reviews need human judgment. Infrastructure costs are excluded from model reservation coverage. This is not an arbitrary repository runner, hosted Alpha worker or organization product.

Implementation details and reproduction commands: [Golden Work guide](../../engineering-golden-work.md). Exact organization/identity work remaining: [EP02 delta](../../plans/2026-09-25-ep02-organization-delta.md).
