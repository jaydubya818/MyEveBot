## What this local envelope means

`MYEVE_FACTORY_RETURN_FIXTURE_V1` is a **synthetic MyEve custody envelope**, not a claimed MyFactory API. `binding` and `sourcePin` are local metadata; `reported` contains strict bounded projections of actual Factory fields; `artifacts` contains synthetic copied bytes. The fixture's Factory label and version/config pin are supplied separately from provider data. Missing/mismatched pins fail closed.

Trusted expectations supply known WorkOrder, repository mapping, required checks, run/attempt identities and candidate pins. A future adapter must establish and store those independently before evaluating a return; deriving expected values from the same untrusted return defeats the checks. Supplemental reports/events require separate expected digest/reference pins. Primary patch and log references must match candidate/check records; unrelated extra artifacts are denied.

The profile intentionally bounds text to 4,000 characters, exact allowed file paths to 30, checks to 20, artifacts to 24 and 200 KB each, and the serialized return to 600 KB. This is a narrower local profile, not a change to Factory's broader scope or artifact limits. No command, path or returned prose is executed.

## Deferred integration interfaces

1. **Independent return transport:** export authenticated source/deployment/config identity and exact request → WorkOrder → Run → candidate/check/artifact linkage, including bounded artifact bytes and digests. Hosted receipt signatures alone are insufficient. Bind time/freshness and reconcile the same request after UNKNOWN; never blindly submit a new production request.
2. **MyEve storage:** persist local binding before dispatch; atomically store one immutable candidate receipt per binding/WorkOrder/attempt, compare content on duplicate, preserve historical returns and recheck cancellation/current Work. This tranche proves serialized local replay only, not SQL/process-concurrent uniqueness.
3. **Owner-defined writer handoff:** quiesce/reconcile the native writer; fence exact Work revision/generation and route request; acquire candidate custody without transferring Work ownership; independently verify; return control through the same owner service. No parallel writer lease or budget implementation is introduced.
4. **Cancellation:** real transport needs an explicitly authorized agent cancellation mechanism with exact attempt fencing and terminal readback. A local intent or active Run returned by run.cancel is not proof of remote termination.

The next boundary is **C: another independent missing capability (authenticated return/version/artifact transport)**. Writer integration also requires **B**, after that transport is established. This source is **not A: ready for live MyFactory qualification**.
