Fresh per-request challenges authenticate the Factory readback attestation under its receipt key. Only signed request/authority/receipt/Work/run/deadline/spend bindings can settle accounting or establish quiescence; unsigned compatibility fields carry no closing authority. Result custody requires the separately pinned `myfactory-external-alpha` / `external-alpha-result-v1` signing family and a signer distinct from the receipt signer.

The existing operations monitor calls a durable reconciliation sweep over retained authorities. It reads the exact existing request, never issues, claims, mints or redispatches. A new process and duplicate sweep deliveries resume the same authority and retain/settle its Result once. Current owner control and exact Work revision are refreshed under database locks before projection. Cancellation, takeover and stale revisions stop the original request and cannot project stale evidence. Terminal reserved/dispatched operations become UNKNOWN exposure rather than disappearing from settlement.

A signed NONE readback can close a terminal path without inventing candidate Proof. Publication, CI, owner review and owner acceptance remain separate; these Proofs never establish final completion.
